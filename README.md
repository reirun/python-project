## Overview

This repository contains our exploratory data analysis for **Task 4: Personal Loan Marketing Campaign Analysis**. The objective is to analyze customer data from a retail bank's marketing campaign to identify key demographic, financial, and behavioral drivers of personal loan acceptance.

## Dataset Description

The dataset comprises customer-level demographic, financial, and banking relationship features, alongside the binary target indicating whether the customer accepted the personal loan offer.

| Feature | Description |
| :--- | :--- |
| `ID` | Customer's unique identifier |
| `Age` | Customer's age (in years) |
| `Experience` | Years of professional experience |
| `Income` | Annual income (in $1,000) |
| `ZIP Code` | Home address ZIP code |
| `Family` | Family size |
| `CCAvg` | Average monthly spending on credit cards (in $1,000) |
| `Education` | Education level (`1`: Undergrad, `2`: Graduate, `3`: Advanced/Professional) |
| `Mortgage` | Value of house mortgage, if any (in $1,000) |
| `Personal Loan` **(Target)** | Whether the customer accepted the personal loan offer |
| `Securities Account` | Whether the customer has a securities account with the bank |
| `CD Account` | Whether the customer has a certificate of deposit (CD) account |
| `Online` | Whether the customer uses online banking facilities |
| `CreditCard` | Whether the customer holds a credit card issued by the bank |
